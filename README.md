# LAB ROOM v6

เว็บไซต์ต้นแบบระบบจองคอมพิวเตอร์ห้องปฏิบัติการมหาวิทยาลัย
เทคโนโลยี: HTML5 + CSS3 + Vanilla JavaScript + LocalStorage

## UI
- Light green / white university dashboard
- Sidebar navigation
- Cards, status pills, computer grid
- Weekly class schedule table
- Responsive design

## Features
- Dynamic Lab Management
- Auto-create computers by room count
- Dashboard shows room status and available/booked computers
- Class Schedule Management
- Blocks booking when a room has a class
- Computer Management
- Booking Management
- Check-in immediately with booking
- Check-in within 20 minutes after start
- Auto-cancel no-show after 20 minutes
- My Booking
- LocalStorage only

## Run
เปิด `index.html` ด้วย Live Server ใน VS Code


## Version Blue Theme
- เปลี่ยนธีมทุกหน้าเป็นฟ้าอ่อน/ขาว
- เพิ่ม root aliases เช่น dashboard.html และ rooms.html เพื่อให้เปิดตรงจาก Live Server ได้
- ปรับ navigation ให้ลิงก์ถูกต้อง
